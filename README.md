# XR DYNAMICS

Static GitHub Pages portfolio. Edit everything in `main.js`:

- `PROJECTS` — each project: `id`, `name`, `videos` (Google Drive links, `{ image }` or `{ slides }`), `description`, `explain`, `tech`, `link`.
- `TABS` — the rolling cover tabs in the hero; `target` is the `id` of the project each tab scrolls to.
- Cover images live in `assets/tabs/`.
